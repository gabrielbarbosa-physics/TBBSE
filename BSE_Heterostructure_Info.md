# Tight-Binding BSE (TB-BSE) Workflow

This repository contains a full **Tight-Binding Bethe-Salpeter Equation (TB-BSE)** solver in Python. It evaluates excitonic states and optical absorption spectra by constructing the two-particle BSE Hamiltonian in k-space, using real-space hopping parameters generated by **VASP + Wannier90**.

The code is optimized for 2D/3D van der Waals heterostructures (e.g., TMDs on GaAs) by integrating the macroscopic **Rytova-Keldysh screening potential** directly into the momentum-space Coulomb matrix elements.

---

## Complete Tutorial: From VASP HSE06 to Excitonic Spectra

This step-by-step tutorial explains the workflow from the initial ab-initio DFT calculation up to plotting the optical absorption and exciton properties using the provided python script.

### Step 1: Geometric Relaxation (PBE)
Before applying hybrid functionals, ensure your atomic structure (the 2D TMD on the GaAs substrate) is fully relaxed using a standard GGA functional (like PBE or PBEsol).
* Save the relaxed `CONTCAR` as your new `POSCAR`.

### Step 2: Hybrid Functional (HSE06) Static Calculation
To obtain accurate bandgaps and band dispersions necessary for optics, run a static (no structural relaxation) HSE06 calculation on your relaxed structure.
* **INCAR settings**:
  ```ini
  System = HSE06 Static
  ISTART = 0 ; ICHARG = 2
  ISMEAR = 0 ; SIGMA = 0.05
  NELM = 100
  
  # HSE06 Parameters
  LHFCALC = .TRUE.
  HFSCREEN = 0.2
  ALGO = Damped
  TIME = 0.4
  PRECFOCK = Normal
  ```
* Ensure you use a moderately dense K-point grid (e.g., `12 12 1`) in your `KPOINTS` file.
* This run generates a high-quality `WAVECAR` and `CHGCAR`.

### Step 3: Wannierization (VASP + Wannier90)
Now, project the exact HSE06 Bloch wavefunctions into Maximally Localized Wannier Functions (MLWFs). This extracts the tight-binding hopping parameters. We will perform a Non-Self-Consistent Field (NSCF) calculation reading the HSE06 `WAVECAR`.

1. **Modify the INCAR**:
   ```ini
   System = Wannier90 Projection
   ISTART = 1 ; ICHARG = 11  # Read WAVECAR and CHGCAR
   ALGO = None               # NSCF calculation
   NELM = 1
   ISYM = -1                 # Symmetry must be turned off for Wannier90
   LWANNIER90 = .TRUE.
   ```

2. **Create `wannier90.win`**:
   For a typical 2D TMD (e.g., MoS2, WSe2), the standard minimal basis isolates the Transition Metal (TM) $d$-orbitals and Chalcogen (X) $p$-orbitals.
   ```ini
   num_wann = 11      # Example: 5 d-orbitals (Mo) + 3 p-orbitals * 2 (S)
   num_iter = 100
   
   # Essential flag to output the hopping matrix for our Python code
   write_hr = true
   
   begin projections
    Mo: d
    S : p
   end projections
   
   # The MP grid must exactly match the VASP KPOINTS grid
   mp_grid = 12 12 1
   begin kpoints
   ...
   end kpoints
   ```

3. **Run VASP**: 
   Executing VASP will now trigger the Wannier90 library. It minimizes the orbital spread and generates the most crucial file: `wannier90_hr.dat`.

### Step 4: Solving the TB-BSE
Move the generated `wannier90_hr.dat` file into the same directory as the provided Python script `tb_bse_solver.py`.

* **Dependencies**: You need standard scientific Python libraries.
  ```bash
  pip install numpy scipy matplotlib
  ```
* **Execution**:
  ```bash
  python tb_bse_solver.py
  ```

### Step 5: Plotting Excitonic Properties and Absorption
When the Python script finishes executing, it will automatically:
1. **Print Exciton Binding Energies**: It diagonalizes the two-particle BSE matrix and prints the binding energies of the $1s, 2s, 3s \dots$ exciton states relative to the HSE06 quasiparticle bandgap.
2. **Plot Optical Absorption**: It calculates the imaginary part of the dielectric function using the Elliott formula mapped onto the Wannier basis. The results are saved as `tb_bse_absorption.png`, clearly showing the pronounced excitonic peaks below the fundamental gap.
3. **Exciton Wavefunctions**: While the script natively calculates the exciton eigenvectors $A_{cv\mathbf{k}}$ in momentum space (which dictate the oscillator strength), these coefficients can be Fourier transformed back to real-space if you wish to visualize the radial envelope of the electron-hole pair.

> **Note**: If `wannier90_hr.dat` is missing, `tb_bse_solver.py` contains a fail-safe that automatically generates a dummy 2-band square-lattice tight-binding model so you can test the mathematical solver and plot generation immediately.
